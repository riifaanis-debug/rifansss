# إضافة وسم تحقق فيسبوك للنطاق

## الهدف
إضافة وسم Meta Tag للتحقق من ملكية النطاق في فيسبوك إلى `<head>` في HTML الفعلي للموقع، دون تغيير أي تصميم أو محتوى أو وظائف أخرى.

## الخطوات

1. **إضافة وسم Meta في Root Route**
   - الملف: `src/routes/__root.tsx`
   - الإجراء: إضافة العنصر التالي إلى مصفوفة `meta` داخل `head()`:
     ```
     { name: "facebook-domain-verification", content: "7bs7870l9uep8q19aa986ardridass" }
     ```
   - السبب: Root Route يضمن ظهور الوسم في `<head>` لجميع الصفحات بما فيها الصفحة الرئيسية `https://rifanss.com/`， وسيظهر مباشرة في HTML الخام عند عرض "View Page Source".

2. **التحقق من البناء**
   - تشغيل فحص TypeScript/BUILD للتأكد من عدم وجود أخطاء ناتجة عن التعديل.

3. **نشر التحديث على Production**
   - استخدام `preview_ui--publish` لنشر الموقع على الدومين الرئيسي `rifanss.com`.
   - بعد النشر، التحقق من أن الوسم يظهر في HTML المنشور.

## ملاحظات
- لن يتم تعديل أي ملف آخر.
- لن يتم تغيير أي تصميم أو محتوى أو وظيفة موجودة.
